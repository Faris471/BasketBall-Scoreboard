# 🏀 Basketball Scoreboard

A simple Home vs. Away basketball scoreboard.

**🔗 Live demo:** https://faris471.github.io/BasketBall-Scoreboard/

## Features

- Separate scores for the Home and Away teams
- +1, +2 and +3 buttons for free throws, field goals and three-pointers
- Scoreboard-style digital font

## Built with

- HTML5 & CSS3
- Vanilla JavaScript

## Run it locally

```bash
git clone https://github.com/Faris471/BasketBall-Scoreboard.git
```

Then open `index.html` in your browser.

## What I learned

- Selecting elements with `getElementById`
- Handling button clicks with functions that take parameters
- Converting text to numbers with `Number()`
- Using custom fonts with `@font-face`
